# Project Brief: 氡气监测系统
*Version: 1.0*
*Created: 2024-07-07*
*Last Updated: 2024-07-07*

## Project Overview
本项目是一个基于HC32F460微控制器的氡气监测系统，用于实时监测环境中的氡气浓度、氡子体浓度、钍子体浓度等参数，并通过串口通信向上位机上报数据。系统具备报警功能，能够在检测到异常值时发出警报，并支持远程参数配置和控制。

## Core Requirements
- 实现氡气浓度、氡子体浓度、钍子体浓度的实时监测
- 支持串口通信协议，与上位机进行数据交互
- 提供报警功能，当监测值超过阈值时发出警报
- 支持时间同步、参数设置和设备控制
- 提供设备状态监控和故障诊断功能
- 确保系统稳定运行，支持长期连续工作

## Success Criteria
- 氡气浓度测量精度达到国家标准要求
- 系统能够稳定运行30天以上无需重启
- 串口通信传输成功率大于99.9%
- 数据采集和处理延迟小于1秒
- 报警触发延迟小于0.5秒
- 电源故障后能自动恢复工作状态
